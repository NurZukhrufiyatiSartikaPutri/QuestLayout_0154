# Pertemuan4 — Biodata Mahasiswa

## Deskripsi

Aplikasi Android sederhana yang dibuat menggunakan **Kotlin** dan **Jetpack Compose** untuk menampilkan informasi program studi, universitas, dan biodata mahasiswa.

## Tampilan Aplikasi

Aplikasi dijalankan menggunakan emulator **Pixel 6 API 37.2** di Android Studio.

## Fitur

* Menampilkan nama program studi Teknologi Informasi.
* Menampilkan nama Universitas Muhammadiyah Yogyakarta.
* Menampilkan logo UMY.
* Menampilkan nama dan alamat mahasiswa.
* Menampilkan informasi program studi pada kartu biodata.
* Menampilkan teks copyright di bagian bawah layar.

## Teknologi yang Digunakan

* Kotlin
* Android Studio
* Jetpack Compose
* Material 3
* Android Emulator

## Cara Menjalankan

1. Buka project `Pertemuan4` di Android Studio.
2. Tunggu proses Gradle Sync selesai.
3. Pilih emulator Android, misalnya Pixel 6.
4. Klik **Run** untuk menjalankan aplikasi.
